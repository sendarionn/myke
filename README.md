# myke

iOS向け日本語キーボードのネイティブプロトタイプ

このリポジトリはCodexを使用して実装した

## 必要環境

- macOS
- Xcode 26以降
- XcodeGen
- iOS 17以降のiPhone

## Xcodeプロジェクトの生成

```sh
xcodegen generate
open myke.xcodeproj
```

## 実機へのインストール

1. Xcodeで`myke`プロジェクトを開く
2. `myke`ターゲットのSigning & Capabilitiesで自分のTeamを選ぶ
3. `mykeKeyboard`ターゲットでも同じTeamを選ぶ
4. Bundle Identifierが重複する場合は、両ターゲットの`dev.sendarionn`部分を固有の値へ変更する
5. iPhoneをMacへ接続し、実行先として選ぶ
6. `myke`スキームを実行する
7. iPhoneでmykeを開き、画面内のキー入力を確認する

## Keyboard Extensionの有効化

1. iPhoneの「設定」を開く
2. 「一般」→「キーボード」→「キーボード」→「新しいキーボードを追加」を開く
3. `myke`を選ぶ
4. テキスト入力欄で地球儀キーを長押しし、`myke`へ切り替える
5. 5行×4列のキーで入力する

「フルアクセスを許可」は不要

キーボードの設定変更が必要になった場合は、`設定`→`一般`→`キーボード`→`キーボード`→`myke`から開く

## テスト

```sh
swift test
```

同じ入力ロジックとazooKeyの同梱辞書を使い、かな入力、派生文字、状態遷移、かな漢字変換を検証する

## 入力方法

- 母音キーはその文字を入力する
- 子音キーはあ段を仮入力し、続けて母音キーを押すと対応するかなへ置き換える
- 別の子音キーを押すと直前の文字を残し、次の仮入力を始める
- 「わ」→「う」で「ん」を入力する
- 上部の「派生」候補から濁音、半濁音、小書き文字、促音を選ぶ
- 未確定文字列がある状態で「空白」を押すと、ひらがな、カタカナ、かな漢字変換候補を表示する
- 上部の「変換」候補を横へスクロールし、候補を押して確定する
- 「確定」は変換せずに現在のひらがなを確定する
- 未確定文字列がない状態で「空白」を押すと空白を入力する
- 「削除」は仮入力中の文字を優先して1文字削除する
- 「、。」「記号」「絵文字」は上部に候補を表示する

## 変換エンジン

- `AzooKeyKanaKanjiConverter` `0.11.2`を使用する
- デフォルト辞書をアプリとKeyboard Extensionへ同梱する
- 変換は端末内で実行し、外部通信を使用しない
- ニューラル変換と学習機能は使用しない
- ライセンスは[THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)に記載する

Debugビルドでは親アプリが約98 MB、Keyboard Extensionが約49 MB、辞書リソースが約38 MBになる

## 実機確認

1. 親アプリで「か」「わ」→「う」「さ」→「い」→派生の「じ」を入力する
2. 「空白」を押し、「漢字」を選んで入力欄が置換されることを確認する
3. 「は」から「ば」と「ぱ」、「た」→「う」から「っ」、「や」から「ゃ」を選べることを確認する
4. 「きょうはいいてんきです」を入力して「空白」を押し、文章候補を選べることを確認する
5. iPhoneの設定でmykeを有効化し、メモなど他アプリの入力欄でも1から4を確認する
6. 候補選択後に続けて入力し、重複や欠落がないことを確認する
7. 入力途中と変換候補表示中に「削除」を押し、末尾の1文字だけが削除されることを確認する
