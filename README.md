# myke

iOS向け日本語キーボードのネイティブプロトタイプ

このリポジトリはCodexを使用して実装した

## 必要環境

- macOS
- Xcode 26以降
- XcodeGen
- iOS 17以降のiPhone

## Xcodeプロジェクトの生成

```sh
xcodegen generate
open myke.xcodeproj
```

## 実機へのインストール

1. Xcodeで`myke`プロジェクトを開く
2. `myke`ターゲットのSigning & Capabilitiesで自分のTeamを選ぶ
3. `mykeKeyboard`ターゲットでも同じTeamを選ぶ
4. Bundle Identifierが重複する場合は、両ターゲットの`com.example`部分を固有の値へ変更する
5. iPhoneをMacへ接続し、実行先として選ぶ
6. `myke`スキームを実行する
7. iPhoneでmykeを開き、画面内のキー入力を確認する

## Keyboard Extensionの有効化

1. iPhoneの「設定」を開く
2. 「一般」→「キーボード」→「キーボード」→「新しいキーボードを追加」を開く
3. `myke`を選ぶ
4. テキスト入力欄で地球儀キーを長押しし、`myke`へ切り替える
5. 5行×4列のキーで入力する

「フルアクセスを許可」は不要

キーボードの設定変更が必要になった場合は、`設定`→`一般`→`キーボード`→`キーボード`→`myke`から開く

## テスト

```sh
swift test
```

同じ`InputEngine.swift`を使い、母音、子音、置換、確定、削除、直接入力、全かな行を検証する

## 入力方法

- 母音キーはその文字を入力する
- 子音キーはあ段を仮入力し、続けて母音キーを押すと対応するかなへ置き換える
- 別の子音キーを押すと直前の文字を残し、次の仮入力を始める
- 「確定」は仮入力を終了する
- 「削除」は仮入力中の文字を優先して1文字削除する
- 「、。」「記号」「絵文字」は上部に候補を表示する

## 対象外

- かな漢字変換
- 辞書と学習
- 同時打鍵
- 濁音と半濁音
- 小書き文字
- App Store公開対応
